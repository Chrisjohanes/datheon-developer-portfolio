# Datheon Developer Portfolio

A personal developer portfolio built with HTML, CSS, and JavaScript to showcase projects, technical skills, and my development journey.

## About the Project

This portfolio presents my background as an aspiring developer, the technologies I am exploring, and selected projects I have worked on. It features a responsive layout, interactive project details, and a theme switcher for a comfortable browsing experience.

## Features

- Responsive layout for desktop and mobile devices
- Mobile navigation menu
- Dark and light theme toggle with saved preference
- Interactive project details modal
- Resume link
- Contact links to GitHub and email

## Getting Started

### Prerequisites

- A modern web browser
- Visual Studio Code (recommended)
- Live Server extension for local development (optional)

### Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/Chrisjohanes/datheon-developer-portfolio.git
   ```

2. Open the project folder in Visual Studio Code.

3. Open `index.html` using Live Server, or open the file directly in your browser.
